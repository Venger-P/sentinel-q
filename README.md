# Sentinel-Q

**Model-free adversarial detection with attack type profiling.**

Sentinel-Q — это библиотека и HTTP-сервис для обнаружения
adversarial-примеров без доступа к целевой модели. Работает на
байтовых характеристиках входных данных, использует метрику
хрупкости сжимаемости (`frag`), и различает типы атак.

## Зачем это нужно

Классические детекторы adversarial-атак (MagNet, Feature Squeezing,
LID, ART) требуют доступа к целевой модели, её градиентам или
логитам. В реальных системах это не всегда возможно:

- Модель — чёрный ящик (сторонний API).
- Модель работает на другом сервере.
- Модель защищена (adversarial training) и обмануть её сложно,
  но атаки всё равно нужно детектировать.

**Sentinel-Q работает без доступа к модели.** Он анализирует только
байтовое представление входных данных и сравнивает его с эталонным
распределением для каждого класса.

Это **side-channel детектор**, который ставится перед моделью как
firewall.

### Текст (character-level атаки)

Первый тест Sentinel-Q на **текстовых данных**. Корпус — docstrings
стандартной библиотеки Python, объединённые в тексты ~1000+ символов.

**Версия 2 (усиленный сигнал):** frag усреднён по zlib + bz2 + lzma,
тексты длиннее, атаки сильнее (`rate = 0.15`).

| Атака | Δfrag | SNR | AUC |
|---|---|---|---|
| swap | −0.076 | 1.62 | **0.997** |
| insert | −0.074 | 1.58 | **0.995** |
| delete | −0.063 | 1.34 | **0.972** |
| homoglyph | −0.032 | 0.68 | **0.946** |
| word_replace | −0.006 | 0.12 | **0.491** |

**Ключевые результаты:**

1. **Swap — прямое доказательство независимости от H.** Атака
   меняет порядок символов, но не распределение. ΔH = **0.0000**,
   Δfrag = **−0.076**, AUC = **0.997**. Это **третье независимое
   подтверждение** (после MNIST и CIFAR), что `frag` измеряет
   пространственную структуру.

2. **Character-level атаки детектируются надёжно.** Три из четырёх
   имеют AUC > 0.97. Homoglyph (визуально идентичная подмена) —
   0.946.

3. **Word-level атаки НЕ детектируются.** Замена слов на синонимы
   меняет семантику, но не байтовую структуру. AUC = 0.49 —
   случайное угадывание. Это **честная граница применимости**:
   `frag` видит байты, а не смысл.

4. **SNR-гипотеза подтверждена на 5-м датасете:**

| Домен | Δfrag | SNR | AUC |
|---|---|---|---|
| MNIST | 0.122 | 1.67 | 0.99 |
| Текст v2 (swap) | 0.076 | 1.62 | **0.997** |
| Текст v2 (insert) | 0.074 | 1.58 | 0.995 |
| CIFAR-10 | 0.024 | 0.45 | 0.75 |
| Текст v1 (rate=0.05) | 0.014 | 0.23 | 0.64 |

Порядок AUC полностью соответствует порядку SNR. При SNR > 1.5
детектор работает отлично. При SNR < 0.5 — плохо.
